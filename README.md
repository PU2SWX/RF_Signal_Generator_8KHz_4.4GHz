PT-BR:

Firmware para ESP32 que controla um sintetizador PLL ADF4350/4351 em conjunto com um Si5351, cobrindo uma faixa contínua de 8 kHz a 4,4 GHz através de uma única interface (display TFT ST7735 + encoder rotativo com botão). O firmware decide automaticamente qual chip usar para cada frequência, com histerese na troca e chave de RF por relé/PIN diode selecionando a saída ativa. Interface com duas páginas: frequência/potência e ajuste independente da referência de cada módulo. Desenvolvido por PU2SWX.

EN:

ESP32 firmware that drives an ADF4350/4351 PLL synthesizer alongside a Si5351, covering a continuous 8 kHz–4.4 GHz range through a single interface (ST7735 TFT display + rotary encoder with pushbutton). The firmware automatically selects which chip drives the output for a given frequency, with hysteresis and a relay/PIN-diode RF switch selecting the active path. Two-page UI: frequency/power on one page, independent reference tuning for each module on the other. Developed by PU2SWX.
